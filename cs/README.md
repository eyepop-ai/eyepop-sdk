# EyePop.Sdk

.NET client for the EyePop pipeline API.

> **Pre-release.** The package currently exposes only `EyePop.Client.Version()`. The pipeline API is not implemented yet.

```
dotnet add package EyePop.Sdk --prerelease
```

```csharp
Console.WriteLine(EyePop.Client.Version());
```

Source and issues: https://github.com/eyepop-ai/eyepop-sdk
