# EyePop Go SDK

Scaffold package. Version comes from the git tag `go/vX.Y.Z` (no file holds it).

Module path is `github.com/eyepop-ai/eyepop-sdk/go/v4`: Go requires a `/vN` suffix on the module path for major versions 2 and up.

`Version()` reports the module version when consumed as a dependency and `(devel)` when built from this checkout.
